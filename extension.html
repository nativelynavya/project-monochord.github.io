PROJECT MONOCHORD · EDUCATOR EXTENSION

Get the Educator Browser Extension

Create a custom chord sonification and export a WAV audio file directly from your Chrome or Edge toolbar.

Download the Project Monochord Extension

Install in Chrome or Edge

  1. Download and extract the ZIP file.
  2. Open chrome://extensions in Chrome or edge://extensions in Edge.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the extracted monochord-extension folder.
  5. Pin Project Monochord to the toolbar, then open it to create and export a graph sonification.

The extension requests no browser permissions. Its source files are available in the Project Monochord GitHub repository.
