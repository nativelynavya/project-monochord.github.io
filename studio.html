Monochord Educator Studio: Custom Graph Sonifier

Make a graph lesson your students can explore visually and by sound. Compare one or two data curves through a polyphonic chord progression.

Create a custom graph

Plot one or two data series, add custom X-axis positions, then explore the graph visually or by listening to its chord progression.

Use 2–40 comma-separated finite values for each series. X-axis values can be numbers or labels such as years; include units in the Y-axis label.

Leave Curve B empty for a single-curve graph. When present, it must have the same number of values as Curve A.

Paste rows with two columns (X, Curve A) or three columns (X, Curve A, Curve B), or a public Google Sheets URL. Data is parsed automatically.

Explore the curve

Focus the graph and use the Left and Right Arrow keys to move between points. In Blind Mode, both curve values are spoken before their chord plays.
